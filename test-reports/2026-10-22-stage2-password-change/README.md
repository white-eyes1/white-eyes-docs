### 시안과 다른 점
- 입력 칸 위치·간격, 안내 문구, 색(통과 초록·불일치 빨강), 버튼 위치는 같다. 변경 버튼 글자 굵기만 시안이 더 가늘다(확인 필요).
- 시안에 없는 상태(03·04·05)는 screens.md 처리 규칙대로 만들었다.
- 사용자 앱 화면은 사용자 앱 로그인(#126)이 없어 캡처하지 못했다(검증 불가). 같은 템플릿이라 헤더의 부제만 '혼잡 현황'으로 다르다.
