# 사용자 앱 기능 명세 (FNC-U-*)

> 원본: 명세서 시트 '기능 명세서(일반)'에서 옮김. 이후로는 이 파일이 원본이다.


### FNC-U-001 아이디 중복 확인

- **목적/설명**
  회원가입 중 아이디 사용 가능 여부를 확인한다
  목적: 가입 전 중복 방지
  구현 위치: user
- **사전 조건**: 회원가입 화면
- **입력 항목**: loginId
- **처리 순서**
  1. 아이디 규칙 검사
  2. user_account에 같은 login_id가 있는지 확인(탈퇴 계정 포함)
- **업무 규칙/검증**: 탈퇴 계정의 아이디도 사용 불가(auth-005)
- **정상 결과**: {available: true/false}
- **예외 상황 및 처리**: 규칙 위반: 400 필드 오류
- **후속 동작**: -
- **관련 요구사항 ID**: auth-001
- **완료/검수 기준**: 탈퇴 계정 아이디가 '사용 불가'로 나오는지 확인

### FNC-U-002 회원가입

- **목적/설명**
  사용자 계정을 만든다. 승인 전까지는 미승인 상태다
  목적: 사용자 계정 생성
  구현 위치: user
- **사전 조건**: 회원가입 화면(SCR-U-001)
- **입력 항목**: 아이디, 비밀번호, 비밀번호 확인, 이름, 메일(선택), 연락처(선택)
- **처리 순서**
  1. 입력값 규칙 검사, 비밀번호 확인 일치
  2. 아이디 중복 재확인(동시 가입 대비 DB 유일 조건으로도 막음)
  3. user_account 저장: status=PENDING, 비밀번호 bcrypt
  4. 가입 완료 안내 후 로그인 화면으로 이동
- **업무 규칙/검증**: 가입만으로는 서비스 이용 불가(관리자 승인 필요). 관리자 계정은 이 화면으로 만들 수 없음
- **정상 결과**: 계정 생성(PENDING)
- **예외 상황 및 처리**: 아이디 중복: 409 DUPLICATE_LOGIN_ID / 검증 실패: 400
- **후속 동작**: 로그인하면 승인 대기 화면
- **관련 요구사항 ID**
  auth-001
  perm-002
- **완료/검수 기준**: 동시에 같은 아이디로 가입 시 하나만 성공

### FNC-U-003 승인 대기 안내

- **목적/설명**
  미승인 사용자가 로그인하면 승인 대기 화면만 보여준다
  목적: 승인 전 이용 차단
  구현 위치: user
- **사전 조건**: PENDING 상태로 로그인
- **입력 항목**: -
- **처리 순서**
  1. 로그인 성공 후 /pending 으로 이동
  2. 다른 경로 요청은 모두 /pending 으로 보냄(API는 403)
- **업무 규칙/검증**: 로그아웃은 가능
- **정상 결과**: ‘관리자 승인을 기다리고 있습니다’ 안내와 로그아웃 버튼
- **예외 상황 및 처리**: -
- **후속 동작**: 승인되면 다음 로그인부터 정상 이용(이미 로그인한 세션은 로그아웃 후 다시 로그인)
- **관련 요구사항 ID**: perm-002
- **완료/검수 기준**: PENDING 계정으로 통계 API 호출 시 403

### FNC-U-004 회원 탈퇴

- **목적/설명**
  비밀번호를 확인한 뒤 계정을 탈퇴 상태로 바꾼다
  목적: 서비스 이용 종료
  구현 위치: user
- **사전 조건**: 내 정보 화면
- **입력 항목**: 비밀번호
- **처리 순서**
  1. 비밀번호 확인
  2. status=WITHDRAWN, withdrawn_at=현재 시각
  3. 이 계정의 모든 세션 삭제
  4. 로그인 화면으로 이동
- **업무 규칙/검증**: 행을 지우지 않음(작업 기록 보존). 같은 아이디로 재가입 불가
- **정상 결과**: 탈퇴 완료 안내
- **예외 상황 및 처리**: 비밀번호 불일치: 400 WRONG_PASSWORD
- **후속 동작**: -
- **관련 요구사항 ID**: auth-005
- **완료/검수 기준**: 탈퇴 후 로그인 거부, 재가입 시 아이디 중복
