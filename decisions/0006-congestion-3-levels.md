# 0006. 혼잡 단계를 정상·주의·위험 3단계로 함

- 상태: 채택 (이전 4단계 여유·보통·혼잡·매우 혼잡을 대체)
- 기록: 2026-10-18
- 출처: 2026-10-18 명세 정리 중 결정(피그마 시안 대조 후 단계 수 변경, 이벤트 시작 단계는 '주의'로 확정). 이전 4단계 이름·0.3 경계는 변경 전 명세 기준이며 이관된 md에는 남아 있지 않다.
- 관련: conventions.md 코드 값 '혼잡 단계'·`THRESHOLD_WARN_DENSITY / THRESHOLD_DANGER_DENSITY`·'혼잡 단계 판정', api/public.md `GET /api/v1/meta/levels`, features/admin.md FNC-A-033, overview.md '이벤트'

## 결정
- 단계 이름·개수는 화면 시안(피그마)에 맞춰 1 정상 / 2 주의 / 3 위험으로 하고, 기준은 밀집도(명/㎡)를 유지한다.
- 경계: 주의 0.7, 위험 1.5(실제 영상으로 조정, evthres-002). 색: #3BC99B / #F59E0B / #EF4D55.
- 혼잡 이벤트(CONGESTION)는 '주의' 이상에서 열고, 열려 있는 동안 '위험'으로 오르면 최고 단계만 갱신한다. '주의' 아래로 5분(EVENT_CLOSE_HOLD_MIN) 유지되면 닫는다.

## 근거
- 이전 4단계의 '혼잡(0.7)'이 '주의', '매우 혼잡(1.5)'이 '위험'으로 옮겨져 이벤트 동작이 이전과 같다. 이전 '보통' 경계(0.3)만 없어졌다.
- '위험'에서만 열면 peak_level이 항상 3이 되어 의미가 없고 이벤트가 늦게 생긴다.
- 밀집도는 면적으로 나눈 값이라 구역·동·구·시에 같은 기준을 쓸 수 있다(overview.md '이벤트 > 기준').

## 영향
- threshold_snapshot은 {warnDensity, dangerDensity}로 저장한다.
