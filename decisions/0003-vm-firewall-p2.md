# 0003. VM별 방화벽(ufw)을 2순위로 미룸

- 상태: 채택
- 기록: 2026-10-18
- 관련: backlog-p2.md '10. VM별 방화벽(ufw)', '5. 망 분리(DMZ)', overview.md 알려진 한계 10

## 결정
VM마다 ufw로 서버 간 접근을 막는 작업을 2순위로 옮긴다. 망 분리(DMZ)는 이 작업 뒤에 한다.

## 근거 (backlog-p2.md에서 인용)
"시연은 local·dev의 호스트 전용 내부망에서 하고, 외부에서 들어오는 길은 웹 서버 웹 포트와 입구 서버 SSH뿐이다. 기능과 관계없는 인프라 작업이다."

## 영향
- 서버 주소는 모두 환경변수로 넣고 VM별 IP·포트 표를 유지한다.
- 관리자 앱 ↔ 분석 서버 요청은 X-Internal-Token으로 확인해 둔다(conventions.md '내부 통신 인증').
- 구현할 때 주의: Docker는 연 포트에 대해 ufw를 우회한다(host 네트워크 모드), 방화벽을 켜기 전에 SSH 허용 규칙부터.
