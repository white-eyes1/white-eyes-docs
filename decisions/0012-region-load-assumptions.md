# 0012. 행정구역 초기 적재(FNC-A-012) 구현에서 명세에 없어 가정한 것

- 상태: 제안 (PM 확인 대기)
- 기록: 2026-10-19
- 이슈: white-eyes-spring [#7 [FNC-A-012] 행정구역 초기 적재](https://github.com/white-eyes1/white-eyes-spring/issues/7)
- PR: white-eyes-spring [#100](https://github.com/white-eyes1/white-eyes-spring/pull/100)
- 관련: features/admin.md FNC-A-012, tables.md `region`, overview.md '외부 API·서비스'(행정구역 경계)

## 배경
FNC-A-012는 경계 GeoJSON을 `region`에 넣고 중심점을 계산하는 1회 실행 작업이다. 명세에 "경계 데이터 출처는 팀에서 확정"이라고만 되어 있어, 구현하면서 파일 형식과 몇 가지 동작을 가정했다. 명세와 충돌하는 부분은 없다. 아래는 명세에 없어서 구현자가 정한 것이고, 확인되면 이 기록의 상태를 바꾸고 필요한 명세를 고친다.

## 가정한 것 (구현자가 정함)

### 확인이 필요한 것
| # | 가정 | 이유 | 확인할 것 |
|---|---|---|---|
| 1 | 경계 파일 형식은 통계청 SGIS 기준. 최상위는 `FeatureCollection`, 지역마다 `properties.adm_cd`(코드)와 `properties.adm_nm`(이름), 도형은 `Polygon` 또는 `MultiPolygon` | 명세에 형식이 없음 | 실제로 쓸 경계 파일과 형식이 맞는지 |
| 2 | 시·구·동은 코드 자릿수로 구분: 2자리=시, 5자리=구, 7자리=동. 상위 지역은 코드 앞 2자리(구의 상위), 앞 5자리(동의 상위) | "시·구·동을 코드로 묶어 parent_id 연결"을 구현하려고 | 실제 파일의 코드 체계가 맞는지. SGIS는 시도/시군구/읍면동 구조라 '시'가 시도에 해당하고, 시 아래에 구가 있는 경우(예: 수원시 장안구)를 어떻게 다룰지 |
| 3 | 파일에 없는 기존 지역은 삭제하지 않고, 같은 `code`만 덮어쓴다 | 명세가 "code 기준으로 덮어씀"이라고만 함 | 경계 데이터가 바뀌어 없어지는 지역을 삭제해야 하는지 |

### 알려 두는 것 (구현자 판단)
| # | 가정 | 영향 |
|---|---|---|
| 4 | 이름은 `adm_nm`의 마지막 단어만 쓴다 ("서울특별시 종로구 사직동" → "사직동") | 이름에 공백이 있는 지역은 잘릴 수 있음. 실제 파일로 확인 필요 |
| 5 | "파일 형식 오류"를 넓게 해석해 다음을 모두 오류로 보고 전체 취소한다: JSON 아님, 코드 중복, 숫자가 아닌 코드, 이름 50자 초과, 상위 지역이 파일에 없음, 도형 좌표 이상 | 너무 엄격하면 실제 파일이 적재되지 않을 수 있음 |
| 6 | JTS `isValid`(자기 교차 등) 검사는 하지 않는다 | 공공 데이터의 미세 오류를 허용하는 대신, 꼬인 도형이면 중심점이 부정확할 수 있음 |
| 7 | `boundary`에는 파일의 geometry를 그대로 저장한다. `MultiPolygon`도 허용한다 | 섬이 있는 동네를 위해서. #9 구역 미리보기 등 뒤 기능이 `MultiPolygon`을 읽을 수 있어야 함 |
| 8 | 중심점 좌표는 소수점 6자리로 반올림(HALF_UP)한다 | `center_lat/lng`가 `DECIMAL(9,6)`이라서 |
| 9 | 작업이 끝나면 앱을 종료한다(`System.exit`). 실행 중 웹 서버도 함께 뜨고, prod 프로필에서도 막지 않는다 | 이미 켜진 관리자 앱과 포트가 겹칠 수 있음. 명세에 prod에서 막으라는 말은 없음 |

## 아직 검증하지 못한 것
- 실제 MySQL 8.4와 실제 경계 파일로는 실행하지 않았다. 테스트는 H2(MySQL 모드)와 샘플 4개 지역으로만 했다.
- 실행 옵션(`--job`, `--file`) 처리에는 자동 테스트가 없다.

## 영향
- 1·2번이 달라지면 white-eyes-spring `RegionGeoJsonParser`의 `levelOf()`, `parentCodeOf()`, 속성 이름 상수만 고치면 된다.
- 확인된 형식은 features/admin.md FNC-A-012의 '사전 조건'에 쓰고, 이 기록의 상태를 '채택' 또는 '대체됨'으로 바꾼다(CLAUDE.md '결정이 바뀜').
