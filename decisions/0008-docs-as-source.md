# 0008. 명세 원본을 구글 시트에서 white-eyes-docs(md)로 옮김

- 상태: 채택
- 기록: 2026-10-18
- 관련: CLAUDE.md, INDEX.md

## 결정
- 2026-10-18 구글 시트 '명세서 목록'의 1순위 시트와 '2순위 기능' 시트를 이 저장소로 옮기고, 이후로는 md만 고친다. 시트는 동결한다.
- 옮기지 않은 시트: 팀 공지용, 프로젝트 산출물 가이드, WBS, 트러블슈팅(기술), 트러블슈팅(서비스 구성). 기능·화면 시트의 양식 예시 행(FNC-001·SCR-001)도 옮기지 않았다.

## 근거
- 코드는 Claude Code로 작성한다. 명세가 코드 저장소 옆 md에 있어야 에이전트가 필요한 부분만 읽고, 명세 변경도 PR과 diff로 남는다.
- 시트와 md를 둘 다 고치면 금방 어긋난다. 원본은 하나만 둔다.

## 옮긴 방식
- 변환 스크립트로 셀 내용을 바꾸지 않고 옮겼다. 검증 스크립트로 모든 ID(요구 115, 기능 97, 화면 23, API 71, 테이블 19, 설정 항목 89)와 셀의 모든 줄이 md에 있는지 확인했다. 별도 검토자(독립 스크립트)가 레코드 단위 대조·순서·역방향 검사를 다시 해 누락·변형 0건을 확인했다.
- CLAUDE.md, INDEX.md, decisions/는 이관 때 새로 쓴 문서다.
